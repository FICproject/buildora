# BUILDORA 60 - Delivery Partner Portal

Delivery tasks, pickup management, live delivery tracking, earnings, and trip history.

## Structure
- `src/assets/`: Static assets, images, icons
- `src/components/`: Reusable UI components
- `src/layouts/`: Portal layout shells and navigation
- `src/pages/`: Route views organized by domain:
  - `dashboard/`
  - `profile/`
  - `tasks/`
  - `pickups/`
  - `tracking/`
  - `earnings/`
  - `history/`
- `src/routes/`: Application routing configuration
- `src/hooks/`: Custom React hooks
- `src/services/`: Portal-specific API and integration services
- `src/store/`: State management
- `src/types/`: TypeScript type definitions
- `src/utils/`: Helper functions
- `src/config/`: Application configuration
